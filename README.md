# AI Practice Projects

A work in progress Python workspace for hands-on AI engineering experiments.

## Current status

The **All_agents_tutorial/** directory is a starter Python package. Its current **main.py** prints a welcome message; it does not yet implement an AI agent or production service.

This repository will grow as each example is implemented, tested, and documented. The status of a project will be stated clearly in its own folder.

## Planned engineering areas

These are areas for future work, not features implemented in the current starter:

- LLM applications and tool use
- Agent orchestration with LangGraph
- Retrieval-Augmented Generation (RAG) and search
- API integration and backend services
- Evaluation, validation, guardrails, logging, and testing

## Run the current starter

Requires Python 3.12. From the repository root, run:

    cd All_agents_tutorial
    python main.py

Expected output: Hello from all-agents-tutorial!
